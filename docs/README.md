# 文档中心

memos-cli 是面向 Memos `v0.28.x` REST API 的命令行客户端。

## 快速导航

- [安装与升级](installation.md)：跨平台安装、重复执行和升级。
- [授权与配置](authentication.md)：Personal Access Token、配置文件和环境变量。
- [命令参考](cli-reference.md)：全局参数、memo、附件、分享、用户管理和 raw API。
- [运维说明](operations.md)：能力状态、自动化建议和兼容说明。
- [发布与安装入口](release.md)：公开仓库地址、一键安装和质量检查。
